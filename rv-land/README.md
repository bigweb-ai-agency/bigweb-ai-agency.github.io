# RV Land

Карта кандидатов для хранения и **личного ремонта** высокого кемпервана длиной около 7 м. Бюджет покупки $3,000–$15,000. [Публичная карта](https://bigweb-ai-agency.github.io/rv-land/).

## Что исследовано

Обзор всех 50 штатов через публичные каталоги LandCentury и LandSearch; конкретные страницы объявлений, старые MLS-записи и фотографии. В выборке есть земля, небольшие дома, гаражи при домах и коммерческое здание. Недобор до десяти фото-кандидатов по штату показан в data/states.json и интерфейсе. Он не доказывает отсутствие таких предложений на рынке.

Это **кандидаты для следующей проверки**, не готовые разрешённые мастерские. Ни у одного нового объекта право личного ремонта и возможность въезда высокого 7-метрового RV не подтверждены компетентным органом и замером.

Перелёты: 73 датированных наблюдения Google Flights Explore в Chrome из VNO, London, WAW и CPH, плюс контрольные страницы перевозчиков. Туда-обратно, один взрослый, economy, гибкие поездки примерно на две недели. Разные даты не являются сравнением одной поездки. Checked bag, отдельный билет до EU-шлюза, трансфер, ночёвки и аренда машины не входят в показанную авиастоимость. Все цены — ориентиры поиска, не checkout и не удержанные бронирования.

## Данные

- data/listings.json — долговечная база. ID, first_seen, price_history, status_history и photo_history сохраняются.
- data/states.json — количества и качественный анализ всех штатов. Климатические баллы — авторская оценка, не измерение участка.
- data/flights.json — даты, маршрут, валюта, перевозчик и источник каждого наблюдения.
- data/gateways.json — координаты из [OurAirports](https://ourairports.com/data/). NYC — поиск по городу; для грубой геометрии используется JFK, аэропорт конкретного тарифа ещё надо подтвердить.
- data/corrections.json — проверенные оговорки первоначального исследования. Не использовать как вечное переопределение цены или наличия.
- data/monitor.json — последний запуск, ошибки и 90 последних кратких событий.
- assets/listings/ — неизменённые байты реальных фото/схем из объявлений, сохранённые по хешу. Права принадлежат авторам/площадкам; рядом доступны ссылки на первоисточник. Изображения не генерируются и не заменяются похожими.
- Первоначальные listings.json, listings-flight.json, photos.js оставлены без изменений. Все 20 старых ID сохранены. Исторический налоговый лот Mankato оставлен без неподтверждённой фотографии и исключён из основной выборки.

live_public_page означает прочитанную публичную страницу. indexed_public_page — поисковый снимок, crawl-возраст хранится отдельно. legacy_unrechecked — прежние сведения, не подтверждённые заново. Надпись “Checked 1 hour ago” из старого снимка не превращается в свежую проверку.

В полной цене отделяются cash price, известный processing/document fee, аукцион, ежемесячный платёж и взнос. Closing, title/escrow, survey, подключения, площадка и ремонт здания остаются отдельными неизвестными затратами. LandCentury хранит денежные поля в **центах**.

## Пригодность

Хранение RV, проживание, личный ремонт и коммерческая автомастерская — четыре разных вопроса. No HOA, agricultural zoning, RV allowed или возможность построить garage не подтверждают остальные.

В [Mohave County IPMC 302.8](https://www.mohave.gov/departments/development-services/building-division/documents/building-ordinance-2021-03/) выявлено ограничение на неходовые машины и крупную разборку с отсылкой к исключениям zoning. Для участков округа стоит отдельный флаг; разрешение устанавливается по parcel и фактической юрисдикции. Материалы заседаний других округов не трактуются как автоматически принятый закон.

Подъезд оценивается по прямой ×1.25 и 75 км/ч. Это не routing API: пробки, горные дороги, пересечения воды, паромы и границы не рассчитаны. Alaska/Hawaii требуют отдельной логистики. До сделки проверить маршрут и parcel в Google Maps, county GIS, FEMA и документах title company.

Шкала задаёт очередь осмотра: цена 25, помещение 25, подтверждение личного ремонта 20, коммунальные сведения 10, сезон 10, путь от шлюза 10. Неизвестный ремонт даёт 0 в компоненте и ограничивает итог 64/100. Это не финансовая оценка или рекомендация купить.

## Ночное обновление

GitHub Actions RV Land nightly discovery — ежедневно **00:37 UTC** (03:37 летом / 02:37 зимой в Вильнюсе), с возможной задержкой GitHub. Доступен ручной workflow_dispatch. Источник: LandCentury, две публичные страницы каждого типа по каждому штату, до 60 новых и до 60 давно проверенных карточек за запуск.

Дополнительная ночная Codex-задача в 05:10 по Вильнюсу проверяет сборщик, ищет новые здания/гаражи и недостающие штаты в других публичных источниках, еженедельно освежает перелёты. Она зависит от доступности среды Codex; GitHub-сбор выполняется независимо.

Сборщик перечитывает robots, не использует скрытые API, не обходит CAPTCHA/403/429. Ошибка сети не означает продано. Исчезновение из выдачи не удаляет запись. Явные изменения статуса добавляются в историю. Новые фото сохраняются в репозитории; прежние файлы не удаляются.

GitHub может приостановить расписание неактивного публичного репозитория. Последний реальный запуск виден в карте и [Actions](https://github.com/bigweb-ai-agency/bigweb-ai-agency.github.io/actions/workflows/rv-land-nightly.yml). Наличие YAML не доказывает успешное выполнение.

## Локальная проверка

Python 3.12+:

    python -m pip install -r rv-land/requirements.txt
    python -m unittest discover -s rv-land/tests -v
    python rv-land/scripts/validate_data.py
    node --check rv-land/app.js
    python -m http.server 8768 --bind 127.0.0.1

Открыть /rv-land/ через localhost. Проверить desktop/mobile, фильтр гаражей, штат, карточку/маркер, историю, избранное, даты тарифа и калькулятор.

Ограниченное свежее испытание:

    python rv-land/scripts/nightly.py --states IL --pages 1 --new-limit 3 --refresh-limit 3

Обычный ночной запуск — без параметров. build_data.py --bootstrap, seed_flights.py и seed_corrections.py предназначены для первоначального импорта. **Не запускать ночью поверх актуальной базы.** Сырые локальные кэши сайту не нужны и не публикуются.

## Публикация и восстановление

Разрешённая область — только rv-land/ и .github/workflows/rv-land-nightly.yml. Не изменять другие приложения репозитория. Перед push проверить свежий main и параллельные изменения. При конфликте сохранить обе версии и объединить осмысленно.

Исходная версия: 136279791d376197b0c400bd88e680032c7dfb3f. Откат интерфейса — восстановить только нужные файлы rv-land из выбранного коммита. **Не откатывать поверх новых данных и фото** без их сохранения. Git хранит опубликованные версии.
